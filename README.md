## Содержимое репозитория

### 1. `student_client_task.py` — Основное задание
Переписан клиент блокчейн-сети на ООП. Содержит два класса: `Block` и `StudentClient`.

#### Классы

##### `Block` (Один блок цепочки)
Основной класс для представления блока блокчейна.

**Атрибуты:**
- `index` — индекс блока
- `surname` — фамилия студента (`Перфильев`)
- `group` — группа студента (`ОКБП-401итмп`)
- `message` — сообщение в блоке
- `prev_hash` — хеш предыдущего блока
- `timestamp` — время создания
- `nonce` — число для майнинга
- `hash` — хеш текущего блока

**Реализованные методы:**
- `calc_hash()` — возвращает SHA-256 хэш от заголовка блока
- `mine()` — Proof-of-Work: увеличивает nonce до тех пор, пока хэш не начнется с 4-х нулей
- `to_dict()` — возвращает словарь со всеми полями блока: index, timestamp, data, surname, group, prev_hash, nonce, hash

##### `StudentClient` (Клиент студента)
Класс, представляющий студента, общающегося с сервером преподавателя.

**Атрибуты:**
- `server` — URL сервера
- `surname` — фамилия студента
- `group` — группа студента

**Реализованные методы:**
- `get_last_block()` — GET запрос к `/last_block`
- `create_block(last, message)` — создает новый Block (использует **и позиционные, и именованные аргументы**)
- `submit(block)` — POST запрос к `/add_block` с телом `block.to_dict()`
- `show_chain()` — выводит текущую цепочку преподавателя
- `run(message)` — главный сценарий работы клиента с циклом попыток майнинга и отправки

**Особенность реализации:**
При создании объекта `Block` в методе `create_block` используются **оба типа аргументов**:
- Позиционные: `last["index"] + 1`, `self.surname`, `self.group`, `last["hash"]`
- Именованные: `message=message`

#### Пример использования
```python
# Создание клиента с именованными аргументами
client = StudentClient(
    server_url="http://127.0.0.1:5000",
    surname="Перфильев",
    group="ОКБП-401итмп"
)

# Вызов метода с позиционным аргументом
client.run("Мой блок на ООП")
```

#### Запуск
```bash
pip install requests
python student_client_task.py
```

**Различия от основной версии:**
