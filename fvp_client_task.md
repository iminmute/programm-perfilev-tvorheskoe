# fvp_client_task.py

## Описание
Адаптированный клиент FVP-сети на объектно-ориентированном стиле (ООП). Содержит два класса: `Block` и `StudentClient`, аналогичные основному заданию, но с терминологией FVP.

## Структура проекта
- `blockchain_work/fvp_client_task.py` — файл реализации для FVP задачи

## Классы

### `Block`
Класс, представляющий один блок FVP-цепочки.

**Атрибуты:**
- `index` — индекс блока
- `surname` — фамилия студента
- `group` — группа студента
- `message` — сообщение в блоке
- `prev_hash` — хеш предыдущего блока
- `timestamp` — время создания блока
- `nonce` — число для майнинга
- `hash` — хеш текущего блока

**Методы:**
- `calc_hash()` — возвращает SHA-256 хэш от заголовка блока
- `mine()` — Proof-of-Work: увеличивает nonce до тех пор, пока хэш не начнется с 4-х нулей
- `to_dict()` — возвращает словарь со всеми полями блока

### `StudentClient`
Класс, представляющий студенческого клиента FVP.

**Атрибуты:**
- `server` — URL сервера FVP
- `surname` — фамилия студента
- `group` — группа студента

**Методы:**
- `get_last_block()` — GET запрос к /last_block
- `create_block(last, message)` — создает новый Block с использованием позиционных и именованных аргументов
- `submit(block)` — POST запрос к /add_block
- `show_chain()` — выводит текущую цепочку FVP
- `run(message)` — главный сценарий работы клиента FVP


## Личные данные
- **Фамилия**: Перфильев
- **Группа**: ОКБП-401итмп

## Пример использования
```python
# Создание клиента с именованными аргументами
client = StudentClient(server_url="http://127.0.0.1:5000",
                       surname="Перфильев", group="ОКБП-401итмп")

# Вызов метода с позиционным аргументом
client.run("Мой блок FVP")
```
