# student_client_task.py

## Описание
Переписан клиент блокчейн-сети на объектно-ориентированный стиль (ООП). Содержит два класса: `Block` и `StudentClient`.

## Структура проекта
- `blockchain_work/student_client_task.py` — основной файл реализации

## Классы

### `Block`
Класс, представляющий один блок цепочки блокчейна.

**Атрибуты:**
- `index` — индекс блока в цепочке
- `surname` — фамилия студента
- `group` — группа студента
- `message` — сообщение в блоке
- `prev_hash` — хеш предыдущего блока
- `timestamp` — время создания блока
- `nonce` — число для майнинга
- `hash` — хеш текущего блока (вычисляется при майнинге)

**Методы:**
- `calc_hash()` — возвращает SHA-256 хэш от заголовка блока
- `mine()` — Proof-of-Work: увеличивает nonce до тех пор, пока хэш не начнется с 4-х нулей
- `to_dict()` — возвращает словарь со всеми полями блока: index, timestamp, data, surname, group, prev_hash, nonce, hash

### `StudentClient`
Класс, представляющий студенческого клиента, общающегося с сервером.

**Атрибуты:**
- `server` — URL сервера
- `surname` — фамилия студента
- `group` — группа студента

**Методы:**
- `get_last_block()` — GET запрос к /last_block
- `create_block(last, message)` — создает новый Block (использует и позиционные, и именованные аргументы)
- `submit(block)` — POST запрос к /add_block с телом block.to_dict()
- `show_chain()` — выводит текущую цепочку преподавателя
- `run(message)` — главный сценарий работы клиента

## Личные данные
- **Фамилия**: Перфильев
- **Группа**: ОКБП-401итмп

## Пример использования
```python
# Создание клиента с именованными аргументами
client = StudentClient(server_url="http://127.0.0.1:5000",
                       surname="Перфильев", group="ОКБП-401итмп")

# Вызов метода с позиционным аргументом
client.run("Мой блок на ООП")
```
